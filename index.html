使用方式與限制
  1. 上傳 PNG、JPEG 或 WebP，至少 256×256 像素。不縮放模型輸入。
  2. 標註 p1–p5；p1、p2 定義基準線，p3、p4 定義骨性頂，p4、p5 定義軟骨性頂。
  3. 可標註 H 的兩個直徑端點。若不提供 H，頭部平移與邊界修復自動停用。
  4. 輸入目標 α，預設保持 β。執行後會下載並在瀏覽器內運行模型；首次約下載 77 MB。
  5. 數值欄位可輸入裁切外的基準線端點。控制點、f* 和 δ 都是操作要求，並非輸出影像的重新量測。

模型原生輸入為 256×256，依 p3–p5 的中心擷取原尺寸影像；裁切外像素保持不變。此模型不提供自動控制點偵測。

生成影像僅供研究展示，未經獨立臨床驗證，不可用於診斷、治療或臨床 Graf 分類。不同角度請求的解剖合理性及教育效益仍需驗證。

網站沒有影像上傳 API、分析追蹤器或影像雲端儲存。模型與推論程式由 GitHub 提供；ONNX Runtime 由固定版本的公開 CDN 提供。
